# ADR 0008 — Vehicle Unity adapter, input layer and driving lab
Status: Accepted (Stage 1 integration), 2026-11-09
Builds on ADR 0004 (physics architecture). Code: `game/Assets/_Project/Vehicle/Runtime`, `Input` (`Game.Controls`), `Camera` (`Game.Cameras`), `UI/Driving`, `Gameplay/DrivingLab*`, `Editor/Setup/DrivingLabSceneBuilder.cs`.

## Decisions
| Topic | Decision | Why |
|---|---|---|
| Rigid body | One PhysX `Rigidbody` per vehicle body; the pure C# model (`VehicleModel`) gets a `ChassisState` each fixed step and returns forces at world contact points (`AddForceAtPosition`). Mass, CoM and the inertia tensor come from the definition; the tensor is diagonalised (Jacobi) into `inertiaTensor` + `inertiaTensorRotation`; automatic CoM/inertia off; damping 0; `sleepThreshold` 0; interpolation on. | PHYSICS_VALIDATION.md §2; colliders must never define mass properties (docs/04 §2.1). Sleeping would snap a truck parked on brakes. |
| Fixed step | `Time.fixedDeltaTime` 0.01 s (TimeManager + bootstrap), max 0.1 s per frame (≤ 10 steps). | docs/04 §1; caps the spiral of death on a hitch. |
| Ground query | `Physics.Raycast` per contact ray (15 per wheel, the core's multi-ray), mask = default layers minus layer 8 `Vehicle`, triggers ignored. Surface coefficients from a `GroundSurface` component on the collider, cached per collider. | Allocation-free; collider tags survive regeneration; physics materials stay for chassis–world friction only. |
| Surface table | `SurfaceTable` in `Vehicle/Runtime`: dry/wet asphalt and concrete copied from the runner; cobbles/gravel/grass are placeholders (WORKING_VALUE, unsourced). | The core has no table yet; request to vehicle-physics to own it (docs/plan/STAGE-1.md). |
| Edge-triggered inputs | The adapter clears `ShiftUp/ShiftDown` after each step. | The core consumes a rising edge; the input bridge runs per frame, physics per fixed step. |
| Tests | PlayMode vehicle tests use `SimulationMode.Script` (`Tick` + `Physics.Simulate(0.01)`), geometry built per test 500 m below any scene content. Zero GC via UTF `Is.Not.AllocatingGCMemory()` with a positive control. | Deterministic, fast, frame-rate independent. Mono in the editor returns 0 from `GC.GetAllocatedBytesForCurrentThread` and the per-frame GC counter is dominated by the test runner. |
| Input layer | `IDriverInput` sources (autopilot, keyboard, touch wheel, gyro, touch pedals/buttons) combined by `DriverInputMixer`: steering = first active source by priority, pedals = max, commands merged. One sign convention: +steer = right. Gamepad/wheel = another `IDriverInput`. | docs/04 §3, gameplay-ui brief. |
| Touch wheel self-centre | Released wheel returns at `rate = maxRate · clamp01(0.6·|v|/8 m/s + 0.4·|Mz|/800 N m)`, none at standstill. | The model exposes only an aligning-torque estimate; a finger cannot be force-fed, so speed + Mz drive a return rate. Documented approximation, to tune in the owner's feel test. |
| Gyro | Gravity sensor (fallback accelerometer) → tilt about the screen normal → minus calibrated neutral (wrapped) → 1€ filter → dead zone → ±35°. Suspend on pause and orientation change. | Neutral subtraction makes the sign independent of the sensor's gravity/reaction convention; on-device axis behaviour still UNVERIFIED. |
| HUD | uGUI built in code. Runtime: Screen Space Overlay (always on top). Visual QA: Screen Space Camera so `Camera.Render` captures it. | World geometry drew over a camera-space canvas near the near plane. |
| Driving lab | Scene, prefab, meshes, textures and materials generated by `DrivingLabSceneBuilder`; layout constants in `DrivingLabLayout` (shared with runtime). The generator re-reads `art-source/truck/dims.json` and fails on drift from `TractorDimensions`. | CLAUDE.md rule 7 (everything as code/data). |
| Sign text | Legacy `TextMesh` with a URP Unlit alpha-clip material (back faces culled, depth-tested). | The font's own GUI/Text shader ignores depth (text showed through the cab and mirrored from behind). TextMeshPro essentials are not imported yet. |

## Consequences
- 60 raycasts per 10 ms step per tractor (≈ 6000/s). Measure on the A16; `RaycastCommand` batching is the fallback if PhysX query cost shows up.
- The trailer adapter (two bodies, `CombinationModel`, no PhysX joint) follows the same pattern; not in DrivingLab yet.
