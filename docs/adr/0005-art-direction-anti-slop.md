# ADR 0005 — Art direction: photographic realism, anti-slop
Status: Accepted (D12), 2026-11-09
Decision: docs/06 is binding. Every visual change passes the visual-qa loop (control cameras → PNG → inspected → compared with owner reference photos) and a visual-critic review before merge.
Consequences: Visual gate blocks merges; "the script passed" is never evidence that something looks right.
