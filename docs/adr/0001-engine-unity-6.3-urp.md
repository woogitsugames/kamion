# ADR 0001 — Engine: Unity 6.3 LTS + URP
Status: Accepted (owner decision D1), 2026-11-09
Decision: Unity 6000.3.28f1 (latest 6.3 LTS patch on start date), frozen in ProjectVersion.txt. URP (Forward+), linear color, IL2CPP, ARM64, Vulkan first.
Consequences: Upgrades to a newer 6.3 patch only via new ADR. HDRP/Unreal/Godot out of scope.
