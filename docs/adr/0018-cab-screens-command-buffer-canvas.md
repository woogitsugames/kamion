# ADR 0018 — Cab screens: own command-buffer canvas into render textures, map data baked offline
Status: Proposed (gameplay-ui agent), 2026-11-09
Context: Review r4 C-N1: the 12.3" cluster, the navigation and the DIN faces were static textures ("82 km/h" while parked, 14:32 at dusk). They must follow the solver on a Helio G99 phone without GC, at 30 Hz for the cluster, and keep `Kamion/Cab Display` (exposure, readability floor, contrast rules) as the material. D20: the cluster is a screen only.
Options: (a) uGUI canvas + camera per screen into a render texture: one URP camera render per screen per refresh (culling, pass setup, ~0.3-1 ms CPU on mobile) and `Text.text` string churn; (b) UI Toolkit panel to render texture: same camera-less path but a layout/text system to keep allocation-free, heavier than the content; (c) own immediate-mode canvas: one mesh, one draw per screen through `Graphics.ExecuteCommandBuffer`, glyphs from the Inter dynamic font atlas at the exact render-texture pixel size, analytic 1-pixel edges for boxes, rings and arcs in one small shader.
Decision: (c), `game/Assets/_Project/UI/CabDisplays` (`DisplayCanvas`, layouts per screen, `CabScreens` component added at runtime by the composition root). Screens bind to the existing `DISPLAY_*` renderers with a material property block on `_BaseMap` (no prefab or material asset change; those two renderers leave the SRP batcher). Render textures sRGB, mip-mapped (seen small and at an angle), resolution by tier (Low 0.5, Medium 0.75, High 1.0 of the design size 1560x600 / 1280x768 / 512x256). Refresh 30/10/1 Hz (Low 20/5/1). Navigation map: `tools/ui/build_nav_map.py` bakes roads (class, name, width), triangulated building footprints and the start route per region into a 100 KB binary (`Resources/CabDisplay/Nav/<id>.bytes`), so the game never parses the 0.5 MB road graph or triangulates.
Consequences: zero GC per refresh (PlayMode test with `Is.Not.AllocatingGCMemory`); layouts are code, versioned and reviewable like the A6 PIL generator they replace at runtime (the A6 textures stay as the static fallback of the prefab). The shared Inter atlas can be rebuilt by other text users; the canvas re-requests its glyphs on `Font.textureRebuilt`. No fuel, weather, game-clock or turn-signal source exists yet: the trip computer estimates fuel from engine power (BSFC 198 g/kWh, WORKING_VALUE), the clock follows the scene sun (`SolarClock`), outside temperature is a scene value, the indicator telltales wait for an input source.
