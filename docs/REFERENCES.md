# Reference images — rules

Owner reference images live in `Data/photos/` (**gitignored**, never published).

## Status of the current set (2026-11-09)
All 16 images were **AI-generated by the owner (GPT image model)**, not photographs. Use them only as:
- **mood / lighting / colour / material-response reference** (Polish overcast daylight, wet-ish asphalt tones, paving blocks, sandwich-panel halls, cab plastics and fabrics);
- **plausibility reference for proportions and layout** (e.g. modern EU cab: steps behind the front wheel, under the rear part of the door; dashboard wrap, cluster in the upper wheel window).

Never use them as:
- **ground truth for real-world geometry** of Białystok (positions, widths, building shapes come only from OSM/GUGiK — ADR 0002);
- **game assets or texture sources** (AI output may hallucinate; texture sources must be our own or CC0 photos);
- **design to copy**: some images resemble real truck brands (e.g. an exterior close to a Scania R/S) and contain real retail logos (TEDi, Sinsay, Pepco, KiK, Kwadrat Park signage). Our truck stays an original TRAKT design; no third-party logos in the game (CLAUDE.md rule 8).

Every visual report that compares against these images must state "AI reference, not photo".

Real photos (phone, owner) remain the gold standard for Stage 3 side-by-side comparisons; when they arrive, name files `real_<place-or-object>_<n>.jpg`.
