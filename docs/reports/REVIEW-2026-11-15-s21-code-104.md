## Werdykt: SCAL (scalony) + follow-up FIX (1× P1, 6× P2) przed APK D67
Kod jest poprawny, mały i dobrze odizolowany. Nic nie blokuje buildu `-Regions d67`. Jedna rzecz wymaga decyzji
lidera albo właściciela przed APK: zestaw `d67` nie zgadza się dosłownie z listą D67 (FIX 1). Pozostałe poprawki to
odporność narzędzi (puste listy, spacje w PowerShell, ścieżka pliku) i drobna odporność runtime.

## Streszczenie zmian
- `Editor/Build/RegionBuildList.cs` + 7 linii w `BuildCommands.cs`: sceny regionów są doklejane tylko do
  `BuildPlayerOptions.scenes`, a `EditorBuildSettings.asset` się nie zmienia. Bez argumentów lista jest identyczna jak
  przed zmianą (`ComposeScenes_NoRegions_KeepsBuildSettingsListExactly`). Region bez zaimportowanej sceny kończy build
  błędem (`return 4`, `BUILD_RESULT: Failed (-regions: …)`), chyba że podano `-regionsAllowMissing`. `-noWorld` działa
  dalej (wywołuje się po doklejeniu regionów i usuwa `_Generated/World`).
- `Gameplay/RegionCatalog.cs` + `Resources/Regions/region_catalog.json` (21 regionów, alias `c`, zestaw `d67`), wspólne
  dla buildu i menu. `World/Runtime/RegionScenes.cs` to jedna reguła nazw scen; `WorldSceneBuilder.SceneNameFor`
  deleguje do niej i zachowuje się tak samo jak poprzednia implementacja.
- Menu: `BootMenu` dostaje wiersz „< region >” i przycisk, `GameBootstrap.BuildRegionChoices`
  (`Application.CanStreamedLevelBeLoaded`), `PlayerPrefs menu.region`, `scene=<id|alias>`.
- Start: `StartRequest.SetRegion` (s = 12 m) → istniejąca ścieżka `ReadRouteArguments` → `RouteSpawnPose`. Do tego
  jednorazowy log `[START] region=… road_edge=…`.
- `scripts/build-android.ps1 -Regions/-RegionsFile/-RegionsAllowMissing` (sufiks `-regions`),
  `scripts/export-region-catalog.py [--check]` (sama biblioteka standardowa), `Data/build_regions.json`.

## Lista FIX (follow-up do main, jeden commit)
1. **P1 — zestaw `d67` a lista D67.** `game/Assets/_Project/Gameplay/Resources/Regions/region_catalog.json:159-161` (`sets`),
   `docs/adr/0229-wybor-regionu-w-buildzie-i-menu.md:30`, test `RegionSelectTests.cs:124` (`AreEqual(17, …)`).
   Propozycja: zostawić `d67` jako trasę główną (zgodna z ADR 0203 wariant A i z „sama trasa główna” z D67) i dopisać
   w ADR §Decyzja 3 jedno zdanie: „odstępstwo od listy D67: Dojlidy poza trasą, Maczka i Kleeberga są na trasie
   głównej”. Dodać zestaw `d67-full` = `d67` + `bialystok-dojlidy`, `knyszyn-w`, `dk65-monki-01`, `dw671-tykocin-01`
   (ESTIMATED 1407–1948 MB, jak `all`). Alternatywa: dopisać Dojlidy do `d67` (+99,6 MB `WORLD_MEMORY` → ≈ 1289–1775 MB
   ESTIMATED). Lider potwierdza z właścicielem (reguła 10: decyzja o zakresie APK).
2. **P2 — odporność `RegionCatalog.Load`.** `game/Assets/_Project/Gameplay/RegionCatalog.cs:82` łapie tylko
   `FormatException`, a `JsonUtility.FromJson` przy uszkodzonym JSON rzuca `ArgumentException`. Wyjątek wyleciałby
   wtedy z `GameBootstrap` przed utworzeniem menu. Propozycja: `catch (Exception e)` (zachowanie bez wiersza regionów).
   Dziś ryzyko jest niskie, bo plik w Resources sprawdza test EditMode.
3. **P2 — pusta specyfikacja po rozwiązaniu.** `game/Assets/_Project/Editor/Build/RegionBuildList.cs:106`: po
   `catalog.Resolve` dodać `if (regions.Count == 0) { error = "-regions/-regionsFile given but resolves to no region"; return false; }`.
   Bez tego `-Regions ','` albo plik z `regions: []` daje zwykły APK nazwany `-regions`, co myli przy pomiarze rozmiaru.
4. **P2 — spacje w `-Regions`.** `scripts/build-android.ps1:47`: zamienić na
   `$regionSpec = ((@($Regions) | Where-Object { $_ }) -join ',') -replace '[\s;]+', ','`. ADR §2 obiecuje spację jako
   separator, a `Start-Process` przekazuje element ze spacją jako dwa argumenty.
5. **P2 — `-RegionsFile` względem bieżącego katalogu i wczesna walidacja.** `scripts/build-android.ps1` (przed
   `Invoke-UnityBatch`): `if ($RegionsFile) { if (-not (Test-Path $RegionsFile)) { throw "-RegionsFile not found: $RegionsFile" }; $RegionsFile = (Resolve-Path $RegionsFile).Path }`.
   Opcjonalnie wczesna walidacja tokenów: `python scripts/export-region-catalog.py --resolve "$regionSpec"` (nowy
   przełącznik), żeby literówka nie kosztowała startu Unity.
6. **P2 — `scene=<id>` dla regionu spoza APK.** `game/Assets/_Project/Gameplay/GameBootstrap.cs:144-148`: przy
   `id != null && !Application.CanStreamedLevelBeLoaded(RegionScenes.SceneNameFor(id))` zalogować
   `[START] region <id> not in this APK` i zostać w menu. Dziś `LoadScene` rzuca błąd, a `-Run` w build-android.ps1 liczy
   to jako exception w logcat.
7. **P2 (kosmetyka) — podwójne wczytanie grafu.** `game/Assets/_Project/Gameplay/DrivingLabBootstrap.cs:378`:
   `RouteGraph.Load` jest wołane drugi raz obok `NavigationInstaller`. To jednorazowa alokacja przy starcie, więc nie
   narusza budżetu GC pętli. Można przekazać graf z instalatora; wystarczy notka.
