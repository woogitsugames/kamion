# B-131 — brama Kwadrat Park: brak kwalifikowanego kadru

Wybrany punkt backlogu: **B-131**, kontekst **B-132** — tablica/pylon i zamknięcie bramy Kwadrat Park przy Andersa 38. To luka trasy C, odrębna od wcześniej obejrzanych BIAFORM i Mickiewicza/Karpińskiego. Celem była konstrukcja bramy i urządzenia wjazdu, bez powielania ogólnych zdjęć ulicy.

Wynik 16.11.2026: **1 rzeczywiście obejrzany kadr, 0 przyjętych referencji bramy, 0 pobrań** (SOURCED: dziennik `observations.json`). Nie zamknięto B-131/B-132 i nie dowiedziono braku bramy.

Istniejący punkt OSM z wcześniejszego P6-G02 posłużył wyłącznie do wyboru miejsca. W publicznym Mapillary z jawnie wybranym **OpenStreetMap** oraz All captures nie było widocznej zielonej sekwencji na sprawdzonym wewnętrznym odcinku przy tym punkcie. To ograniczony wynik danego widoku, nie globalny brak pokrycia. Na Andersa wybrano [kadr grobin 1358439911198809](https://www.mapillary.com/app/?pKey=1358439911198809&focus=photo&mapStyle=OpenStreetMap), **30.08.2019** według UI, i obejrzano osobno także po Maximize.

SOURCED [obraz]: wielopasowa asfaltowa jezdnia przy niskim słońcu, podwójne łukowe wysięgniki lamp w pasie rozdziału, stalowe bariery i duże tablice przy prawej stronie. Treść tych tablic oraz konkretne zamknięcie bramy Kwadrat Park są nieczytelne/niewidoczne. **Odrzucono jako dowód pylonu lub szlabanu.** Nie dodano drugiego ogólnego kadru drogi na siłę. GPS kamery, azymut, aktualność 2026 i identyfikacja tablic pozostają UNVERIFIED; viewport nie jest GPS.
