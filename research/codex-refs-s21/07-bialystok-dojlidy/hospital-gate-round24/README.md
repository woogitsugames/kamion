# B-053 — brama szpitala przy Żurawiej, runda 24

Przegląd: 2026-11-16, bez odtwarzania godziny. **0 nowych obejrzanych fotografii, 0 pobrań i 0 przyjętych referencji.**

Wybrano B-053 / B-130 z backlogu. Istniejący lokalny manifest M62 (`research/mistral/p19-hospital-gate`, P19-001) wskazuje punkt OSM szlabanu 2448457849: 53.109457, 23.190647. To wyłącznie wybór obszaru, nie GPS aparatu.

W [publicznym Mapillary](https://www.mapillary.com/app/?lat=53.109457&lng=23.190647&z=18&mapStyle=OpenStreetMap) potwierdzono w otwartym menu **OpenStreetMap** i **All captures**. Panel filtrów miał puste pola użytkownika oraz dat, tryb Any i wyłączony wymóg 360°. Mapa załadowała Żurawią, portiernię i teren szpitala, lecz nie było widocznej sekwencji do wyboru. Po jednym oddaleniu na najbliższy odcinek Żurawiej/Wiewiórczej wynik pozostał taki sam. Nie sprawdzano serii kolejnych punktów.

To ograniczony wynik UI, nie dowód globalnego braku pokrycia lub nieistnienia bramy. Nie odczytano nowego frameID, autora, daty zdjęcia ani wyposażenia. Aktualny stan bramy i oznakowania pozostaje UNVERIFIED.

Stary M62 F01 / P11-129 (Rakoon, 10.11.2019, CC0) był już opisany. Nie otwierano go jako nowej referencji ani nie kopiowano. B-053 i B-130 pozostają otwarte; manifest ma sam nagłówek.
