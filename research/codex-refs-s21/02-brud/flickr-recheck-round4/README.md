# Flickr — pojedyncza kontrola dostępu, obieg 4

[Dirty — Bill Stilwell / icathing](https://www.flickr.com/photos/icathing/4433883530/) tym razem wyrenderował rzeczywistą fotografię na jednej kanonicznej publicznej fotostronie. **CC BY-SA2.0** i data wykonania **SOURCED [widoczny tekst fotostrony] 17.02.2010**. Wcześniej ten sam URL był tylko kandydatem z czarnym hero; nie liczymy go jako drugiego zdjęcia względem dawnego nieudanego dostępu.

## Co potwierdzono z oględzin

Po niezależnej recenzji: jeden nowo obejrzany NIEJEDNOZNACZNY wzorzec powierzchni podwójnych drzwi. Panele/okucia szarobrunatne, jasna drobna rozgałęziona siatka i pionowe pasma, ciemne zacieki przy dolnych okuciach. Top i próg poza kadrem. Osad/nalot vs spękana/uszkodzona powłoka lub kombinacja pozostaje UNVERIFIED. Wycofano początkową kwalifikację jako potwierdzony brud; same kształty i kolory PASS. Szczegóły peer-review.json.

**SOURCED [DOM img naturalWidth/naturalHeight] 1599 × 1200 px**, wyświetlane **1088 × 816 CSS px**. Obraz oglądany normalnie w Chrome, bez upscalingu narzędziem, pobierania i zapisu zrzutów. Widoczny fragment drzwi ma **ESTIMATED ok.1100–1200 px** wysokości naturalnego obrazu; brak pełnych granic skrzydeł uniemożliwia pomiar pełnej wysokości. Dawne metadane oryginału 3444 × 2584 px nie są rozmiarem oryginału obejrzanego teraz — nie otwierano go.

**Typ naczepy vs solówki/przyczepy pozostaje UNVERIFIED**: brak osi, podwozia i zaczepu; publiczny opis autora to jedynie „Dirty”. Logo Wabash nie rozstrzyga konstrukcji. Kraj, bezpośredni moment względem trasy, sezon zimowy i skład osadu **UNVERIFIED**. Lutowa data nie dowodzi zimowych warunków, a jasne ślady nie dowodzą soli.

Liczniki tego obiegu (manifest.csv / observation.json): **1 nowo obejrzany niejednoznaczny kadr powierzchni;0 potwierdzonych wzorców brudu; 0 potwierdzonych nowych naczep; 0 ścisłego M61; 0 potwierdzonych zimowych/EU; 0 pobranych obrazów**. Liczniki nie zastępują sum całego pakietu.

## Dostęp i ograniczenie prób

Najpierw przeczytano dawny `data/flickr-4433883530-access.json`: błąd direct download429, hero czarny, naturalny rozmiar oryginału0×0. Log nie zachował Retry-After ani czasu odpowiedzi HTTP, więc nie odtwarzano ich z mtime. Teraz wykonano **jedno** otwarcie kanonicznej fotostrony po zwolnieniu Chrome przez agenta Knyszyn: bez reload, bez directstatic, wariantów hostu/parametrów, allsizes, logowania i CAPTCHA. Oględziny zakończone CUA completion_summary, Chrome zwolniony.

Podczas oczekiwania wykonano jeden niezależny odczyt metadanych Commons; nie pobierano żadnego z tych kandydatów ani nie opisywano ich z siatki miniaturek. Dziennik selekcji znajduje się w independent-commons-metadata.json. Pliki ukończonych wcześniejszych zestawów pozostają stabilne.
