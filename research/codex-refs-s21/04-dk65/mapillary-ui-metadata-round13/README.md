SOURCED [publiczny UI każdego obrazu]: oba kadry otwarto oddzielnie, obejrzano fotografię, panel **Image details** i rozwinięcie **Advanced**. To literalne wartości publicznego UI, nie odczyt EXIF ani pomiar pobranego pliku. Autor obu: picturehoover. Panel podaje CC BY-SA z odnośnikiem do wersji 4.0. „Advanced” pokazuje klucz obrazu, klucz capture i czas capture; nie zawiera odczytanych współrzędnych aparatu ani liczbowego azymutu. Nie klikano pobierania, edycji OSM, zgłoszeń ani funkcji NeRF.

**UNVERIFIED:** GPS aparatu, liczbowy heading, odniesienie kierunku do północy geograficznej/magnetycznej, dokładny kilometr i kafel dk65-01…11. Współrzędnych w adresie viewportu oraz linkach otwierających edytory OSM nie przemianowano na GPS aparatu. Sama strzałka kierunku nie daje tu źródłowo odczytanej liczby.

[Oficjalna instrukcja publicznej aplikacji](https://help.mapillary.com/hc/en-us/articles/115001662325-Viewing-imagery-on-the-Mapillary-web-app-the-complete-guide), aktualizacja widoczna w tekście: 18.03.2025, opisuje ikonę kierunku, opcje obrazu i zmianę podkładu. Nie podaje w odczytanej treści numerycznych pól GPS/heading ani odniesienia północy. Instrukcja Desktop Uploader znaleziona w wyszukiwaniu dotyczy innego narzędzia i nie służy do potwierdzenia pól publicznego web UI.

Wynik: 2 ponowne indywidualne oględziny istniejących ekspozycji, **0 nowych fotografii, 0 odczytów GPS aparatu, 0 liczbowych kierunków**. Bez API, GraphQL, ukrytego stanu aplikacji, tokenów, pobrań, zapisanych screenshotów i nowych zapytań Commons/OSM/Overpass. Poprzedni pakiet RV12 pozostaje niezmieniony; historyczne fotografie z 2020 r. nie dowodzą stanu 2026.
