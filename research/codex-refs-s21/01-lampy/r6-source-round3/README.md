# R6 — odnalezione pełne źródło

Pełny oficjalny [R6 Rev.5](https://unece.org/sites/default/files/datastore/fileadmin/DAM/trans/main/wp29/wp29regs/R006r5e.pdf) jest dostępny jako tekst przez web. Dokument z07.10.2011, konsolidacja do Supplement21 serii01. To odrębny adres/wydanie; nie ponawiano dwóch zablokowanych adresów poprzedniego obiegu.

Osiem zwięzłych rekordów SOURCED w regulations.csv uzupełnia wcześniejszą lukę źródłową. Każdy ma punkt i warunki. Nie zmieniono wcześniejszych dzienników. Zero zdjęć i zero nowych zbliżeń homologacyjnych.

Nie deklarujemy aktualności prawnej2026 ani konkretnego certyfikatu5497. Szczegółowa graficzna siatka procentów nie została przerysowana; zasada pomiarów kierunkowych pochodzi z pełnego tekstu. Bitmapa strony PDF była niedostępna(403), co nie zostało ukryte. Bez lokalnej kopii PDF, kodu gry i operacji git.

Koordynator ponownie odczytał pełny oficjalny tekst przez indeksowany PDF. Dodano9.wierszR6-R3-09: ograniczenia sterowania2b z6.6.2, aby1000cd nie odczytywać jako bezwarunkowego maksimum nocnego. Teraz9SOURCED. Bez interpretowania liczby komór zD i bez aktualności2026.
