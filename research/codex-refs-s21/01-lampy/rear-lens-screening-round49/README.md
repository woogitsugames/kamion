# R49 — sprawdzenie fizycznego klosza DAF

Cel: odnaleźć czytelny fizyczny znak homologacji tylnej lampy ciężarowej bez zastępowania oglądu deklaracją oferty.

Obejrzano indywidualnie jeden rzeczywisty kadr klosza trzymanego w ręce, najpierw w ofercie, następnie pod dokładnym adresem obrazu. SOURCED [DOM publicznej przeglądarki]: rozdzielczość 1280 × 591 px. Widoczny podłużny czerwony klosz ma bezbarwne pole po prawej i drobne wytłoczenia na górnym pasie. E, cyfra kraju, numer oraz symbole funkcji pozostają UNVERIFIED. Brak dowodu załączenia.

SOURCED [oferta](https://allegrolokalnie.pl/oferta/klosz-lampy-tylnej-daf-xf-105-106): sprzedawca przypisuje klosz do DAF XF105/106. Nie potwierdzono konkretnego podtypu pojazdu. ESTIMATED z natywnego obrazu: szerokość klosza około 900–950 px (70–74% szerokości fotografii); nieczytelność znaku, a nie wielkość klosza, blokuje zaliczenie.

Bilans: **1 obejrzany kadr, 0 nowych zdjęć w kolekcji, 0 czytelnych E, 0 awansów do tylnego progu M59, 0 ON i 0 nocy**. Nie badano następnego całego klosza z tej samej galerii. Dalsze wyniki wyszukiwania nie zostały opisane jako obejrzane obrazy. Manifest zawiera jeden rekord dokumentacyjny, nie fotografię do licznika.
