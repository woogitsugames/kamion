# Starsze regulaminy — obieg 2

Cel: starsze znaki E i warunki fotometrii bez przypisywania numeru5497 do konkretnego certyfikatu.

Odczytano pełne oficjalne snapshoty [R4 Rev.3](https://unece.org/DAM/trans/main/wp29/wp29regs/2013/R004r3e.pdf) i [R7 Rev.6](https://unece.org/fileadmin/DAM/trans/main/wp29/wp29regs/2015/R007r6e.pdf). Daty, punkty i ograniczenia są przy każdym rekordzie regulations.csv. Zestaw nie deklaruje mocy prawnej2026 i nie obejmuje wszystkich późniejszych zmian. Rewizja dokumentu i seria poprawek są różnymi oznaczeniami.

Pełne R6 pozostaje UNVERIFIED: stary PDF i nowa oficjalna strona publikacji zwracają403. Metadane strony nie zastępują tekstu; nie podano zapamiętanych wartości ani przepisanych z R148. Robocze materiały DETA/SLR z propozycjami zmian znakowania wykluczono. Odczyt2a w przykładzie R4 ma ograniczone znaczenie: przykład funkcji, nie pełna podstawa normatywna R6.

Wnioski użytkowe: klucz funkcji i seria muszą towarzyszyć E-numerowi; zakres osiowy nie wyznacza równomiernej jasności całego pola. Lampy D i sprzężone mają dodatkowe warunki. Tablicę opisuje luminancja powierzchni, nie światłość źródła. Szczegóły liczbowe wyłącznie w CSV.

Licznik pakietu: 13 rekordów (11 SOURCED, 2 UNVERIFIED), 0 zdjęć i 0 nowych homologacyjnych zbliżeń. Pozostała luka: czysty pełny R6, fotometria kierunkowskazu i jego własne reguły symboli/serii. Brak git operacji, brak plików firmowych.
