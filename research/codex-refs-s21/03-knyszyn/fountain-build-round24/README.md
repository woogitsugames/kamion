# Fontanna — rzeczywisty kadr robót, runda 24

Odczyt i ogląd: 2026-11-16, bez odtwarzania dokładnej godziny. Cel: nowa gminna referencja, która mogłaby pokazać faktyczny układ dysz lub krat.

## Wynik

**1 nowa indywidualnie obejrzana ekspozycja historycznych robót; 0 potwierdzonych układów dysz/krat, 0 wymiarów i 0 pobranych fotografii.** To materiał AUX, bez propozycji zwiększania parent kolekcji układu fontanny.

Źródło: [Nowy Goniec Knyszyński nr 3 (184), marzec 2020, s. 11 „Prace na rynku”](https://www.knyszyn.pl/asp/pliki/download/3.pdf#page=11). Wydawca Urząd Miejski w Knyszynie (stopka s. 2); tekst UM Knyszyn, fotografia Urszuli Citkowskiej według kredytu przy serii s. 11. Miesiąc wydania pochodzi z okładki, nie jest datą ekspozycji.

SOURCED [ogląd górnego prawego zdjęcia s. 11 w natywnym Chrome przy 100% i 150%]: odkryty brązowy grunt, większe zagłębienie z pionowymi ścianami, drabina, dwa długie ciemne elementy i mniejsze prostokątne zagłębienia. Brak czytelnego zamontowanego układu dysz i krat. Nie określono funkcji tych ciemnych elementów ani wymiarów wykopu. Pozostałe zdjęcia były widoczne w kontekście całej strony, ale nie są tu osobnymi referencjami.

SOURCED [pełny tekst s. 11]: komunikat mówi o trwającej budowie fontanny i alejek oraz badaniach archeologicznych w wykopie. To informacja o robotach, bez technicznego schematu instalacji i bez protokołu odbioru. Nie przepisano planowanego terminu zakończenia jako rzeczywistej daty wykonania.

**UNVERIFIED:** liczba fizycznych dysz, rozmieszczenie ich osi, liczba obiegów, rozmieszczenie krat, przekrój odwodnienia, metryka instalacji i zgodność wykonania z opisem projektu 2019. Wykop nie jest źródłem finalnego obrysu fontanny.
