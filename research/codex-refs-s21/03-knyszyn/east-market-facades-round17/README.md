## Selekcja, dedup i ograniczenie celu

Przed oglądem odczytano główny manifest03 (40 rekordów), bieżący README i część K1 dotyczącą Rynku/Grodzieńskiej. Na planowanej ulicy południowo-wschodniego boku nie było widocznej zielonej sekwencji; wybrano widoczny północno-wschodni bok. Dwa dokładne ID nie występowały wcześniej w lokalnych s21/K1. To odrębne ekspozycje, ale nie dowód dwóch nowych budynków względem wszystkich odległych teł wcześniejszych kadrów. Znany urząd widoczny w tle nie jest nową referencją bryły. Nie powielono fontanny ani ławki jako celu.

Pełne widoki dachów bliskich fasad nie zostały uzyskane. Nie rozszerzano obiegu o kolejne punkty, aby nie mnożyć podobnych kadrów. Szczególnie drugi obraz przydaje się do geometrii schodów i balkonu, nie do modelowania nieobejrzanego górnego obrysu.
