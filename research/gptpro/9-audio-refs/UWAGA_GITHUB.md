# UWAGA — pliki binarne audio

Ten katalog zawiera część tekstową pakietu G9 (audio-refs): README.md, manifest.csv, sources.md.

Pliki audio z katalogu `files/` (51 nagrań, ~71,5 MB) NIE zostały wgrane do repozytorium,
ponieważ dostępne narzędzie GitHub (MCP) przyjmuje wyłącznie treść tekstową (string), bez
obsługi plików binarnych. Kompletny pakiet `gptpro-9-audio-refs.zip` (README + manifest +
sources + files/, ~71 MB) został przekazany poza GitHub (artefakt do pobrania).

Manifest.csv dokumentuje wszystkie 106 pozycji, w tym te tylko-linkowe (BBC RemArc,
Commons CC BY-SA) — te nigdy nie były częścią plików binarnych.
