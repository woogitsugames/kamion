# Oryginalny EXIF dwóch kandydatów początku trasy

12 listopada około 12:53 wykonano jedno anonimowe zapytanie API Commons o metadata, commonmetadata i size dla cm109685822 oraz cm92458760. Nie pobierano oryginalnych obrazów i nie korzystano z urządzeń. Pełna odpowiedź, URL zapytania i czas są w commons-first300-original-metadata.json.

Oba oryginały mają 4608×2592 px, Orientation=1, Make=samsung, Model=SM-A720F, FocalLength=3,6 mm i FocalLengthIn35mmFilm=27. Nie znaleziono GPSImgDirection ani innego kierunku optycznego. To nowe dane do dalszej kalibracji: dotychczasowe założenie „lokalna miniatura nie ma EXIF” pozostaje prawdziwe dla miniatury, ale nie oznacza braku EXIF w oryginale.

EXIF obu zdjęć podaje tę samą pozycję 53,1527777778 N, 23,1683333333 E. Publiczny geotag Commons cm109685822 wynosi natomiast 53,152931 N, 23,168504 E. Są to różne wskazania źródła; nie wolno arbitralnie zastąpić jednego drugim. Dla cm92458760 publiczny geotag odpowiada EXIF z dokładnością zaokrąglenia. GPSAltitude wynosi odpowiednio 172 i 0 m; nie używać tych liczb do osadzenia oka nad jezdnią.

27 mm eq jest wskazówką optyki, nie gotowym poziomym FOV. Trzeba rozstrzygnąć konwencję ekwiwalentu i crop 16:9 względem sensora, możliwą korekcję programową oraz porównać trwałe kotwice. Orientation=1 nie dowodzi zerowego roll. Na etapie pierwszego odczytu metadane aktualnego pliku na Commons nie były związane bajtowo z lokalną miniaturą; dalszą weryfikację opisano poniżej. Produkcyjne kamery i referencje pozostają bez zmian, nadal C. Przygotowane próby r4 dotyczą sześciu innych zdjęć i nie korzystają z tego EXIF.

Uzupełnienie 12:57: dwie aktualne miniatury Commons 3840×2160 pobrano do ignorowanych artefaktów i porównano SHA256 z lokalnymi zdjęciami oraz rejestrem sbs_references. Oba pliki są identyczne bajtowo. Przed i po pobraniu API potwierdziło niezmienne SHA1 oryginałów, czas ich publikacji, URL i wymiary miniatur oraz identyczny EXIF. Receipt source-verification/binding.json ma wynik EXACT_THUMBNAILS_AND_STABLE_SOURCE_METADATA, a dwa pliki metadata-before/after mają identyczne SHA256. Oryginałów 4608×2592 nie pobierano, obrazów nie dekodowano i nie zmieniano referencji. To wiąże pozyskany EXIF z aktualnymi lokalnymi zdjęciami, ale nadal nie potwierdza poprawności GPS ani nie kalibruje pozy.
