## What actually executes

R4PlateGpuProbe.Build reads the pinned shipping WorldCarPlate.shader, changes shader name, the forward fragment entry, and the final vertex clip position. It retains the shipping PlatePassVertex/PlateInstanceUV hash, object-matrix lookup, validity/lightmap/keyword guard and its call to original URP Lit vertex. The adapter then places the actual native plate submesh in a small numeric viewport and returns interpolated UV from a float fragment. It draws native meshes/submesh material slots through RenderMeshInstanced with actual selected WorldInstanceSet matrices; all54 native submeshes are exercised. Cull0, disabled shadows, new clip positions, no lighting fragment/post/MSAA and ARGBFloat RT are deliberate diagnostic changes. This is not a normal scene/phone render or texture-sampling test.

The64x8 RT gives each of four instances a16x8 tile. Samples x7/8 within each tile and y3/4 are symmetric around centre: local U .46875/.53125 and V .4375/.5625. Their average is(.5,.5) with either RT Y direction. CPU Expected uses the same centre of the inset248x54 content, not the cell edge. Hash uses unchecked signed-floor-to-uint arithmetic and the same constants/quarter-metre grid as shipping; expected rebase result intentionally uses original matrix/rect, while GPU receives both shifted together. I found no wrong pixel-centre, hash or cell-decode arithmetic.

Important limit: centre averaging cannot detect mirrored/transposed local UV, endpoint/gutter sampling errors or a symmetric span mistake. Both front/rear quads overlap in the diagnostic projection, so this does not independently distinguish their appearance. Actual54 native corners/orientation are supported separately by native parity validation/source audit; letters/front-versus-rear and actual atlas mips still need focus/native crops.

This tests synthetic common-shift invariance, not WorldInstances.SyncOrigin/component execution, runtime distance LOD selection, arbitrary boundary precision or every floating-origin event.

- Factory idempotence operates on a private set clone and material clone, exercising success twice -> rejected empty prototypes -> restored success, with EditorJsonUtility equality. The generated hidden shader and Editor harness are QA artifacts, not a shipping material binding.
