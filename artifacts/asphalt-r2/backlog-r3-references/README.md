# Przygotowanie referencji do backlogu r3

Te cztery lokalne fotografie Commons zostały obejrzane podczas oczekiwania na slot końcowego GIS r2. Źródła, autorzy, licencje i SHA są w SOURCES.json. Są tylko referencją, nie źródłem tekstur.

Zdjęcia przedstawiają głównie publiczne ulice, chodnik, przystanek i wiadukt. Dwa z 2013 roku pokazują mokre nawierzchnie przy Andersa/Maczka. Nie są wystarczającym dowodem materiału prywatnego placu przemysłowego poza Kwadratem. Nie wolno nazywać ich dopasowaniem takiego placu ani kalibrować na nich suchego albedo. R3 nadal wymaga właściwego doboru miejsca i referencji.

Dalsze sprawdzenie galerii Commons PCRT przy Andersa ujawniło właściwy typ ujęcia: pcrt-20200711-3.jpg pokazuje brukowany plac przed halą z samochodami dostawczymi. Autor Rakoon, CC BY3.0 (potwierdzone API i stroną pliku), 2020-07-11. To kandydat referencyjny materiału r3, nie dopasowana poza: ten plik nie ma współrzędnych. Sąsiednie zdjęcia1/2 dają kontekst ulicy; zdjęcie4 i pcrt-20210328-110541 pokazują wnętrze, więc je odrzucono dla placu. Źródłowe metadata API, licencje, adresy i SHA zachowano. Zdjęcia są wyłącznie referencją, nie teksturą ani wzorem logo.

Lekka konwersja trzech punktów metadanych (coordinate_precheck.py, 0,4s całe wykonanie) wskazuje, że są w regionie C i poza konserwatywnym prostokątem Kwadrat: E355,6..381,6/N-551,7..-388,5. Nie dowodzi to, że cały teren PCRT jest poza tym prostokątem. Przed r3 należy sprawdzić właściwy fragment placu/material ID i pozycję; nie wolno przyjmować tych trzech punktów jako pozy kamery pliku3. Nie edytowano źródeł ani danych geometrycznych dla r3.
